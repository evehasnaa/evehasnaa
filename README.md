## 🏗️ How I Build Pipelines

```
 Raw CSV / API                                          Dashboards
     │                                                       ▲
     ▼                                                       │
 [ Staging ] ──► [ Bronze ] ──► [ Silver ] ──► [ Gold ] ──► [ BI ]
  land raw        typed          cleaned        star         DAX +
  fast            history        conformed      schema       measures
```

| Layer | Tools |
|-------|-------|
| 🥉 Ingestion | Python, pyodbc, PyArrow, chunked loads |
| 🥈 Transformation | T-SQL stored procedures, data cleaning |
| 🥇 Modeling | Star schema, dims & facts, gold views |
| 📊 Serving | Power BI, DAX, TMDL semantic models |
| ✅ Quality | Statistical validation checks in Python |
